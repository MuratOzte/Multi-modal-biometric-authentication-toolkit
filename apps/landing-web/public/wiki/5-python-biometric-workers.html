The Python biometric workers subsystem provides dedicated machine learning and computer vision pipelines for facial verification, voice enrollment and recognition, ID card parsing, and IP reputation checks. The backend integration layer invokes these Python scripts via subprocess bridges with standard input/output contracts or command-line arguments.

The python/ directory houses isolated modules for each biometric modality README.md 27-30 alongside environment configuration scripts README.md 34 and preflight validation tools scripts/biometric-preflight.py 8-14 Each worker runs within its own Python virtual environment to manage dependencies like PyTorch, TorchAudio, Whisper, SpeechBrain, PaddleOCR, and OpenCLIP cleanly without version conflicts.

Face and Voice Workers

The face and voice verification pipelines handle biometric embedding generation, liveness validation, challenge-phrase speech-to-text checks, and speaker similarity scoring README.md 10-11 The face verification module utilizes MTCNN for landmark detection and FaceNet for high-dimensional embedding extraction, supporting sliding-window reference management README.md 10 The voice verification module combines Whisper for transcription and SpeechBrain speaker recognition models README.md 11

For detailed architectures, command-line arguments, input/output JSON schemas, and integration pipelines, see Face and Voice Workers.

Sources: README.md 10-11

Card Verification Worker

The card verification worker (python/card_verification) automates ID document processing by combining PaddleOCR for text extraction and OpenCLIP for visual document similarity comparison README.md 12 It executes via structured configuration files (config.yaml / config.cpu.yaml) and handles image preprocessing, alignment, and robust field extraction README.md 29

For detailed execution scripts, configuration options, and test suites, see Card Verification Worker.

IP Check and Environment Setup

The IP check script (python/ip_check.py) queries reputation services such as VPNAPI to evaluate client network signals, detecting VPNs, proxies, Tor exit nodes, and relay configurations README.md 13 Environment setup involves configuring dedicated virtual environments (.venv-face, .venv-voice, .venv-card) README.md 34 resolving hardware acceleration paths (CPU vs CUDA), and ensuring FFmpeg availability for audio processing README.md 135

For installation instructions, preflight verification scripts scripts/biometric-preflight.py 8-14 and environment variable configuration, see IP Check and Environment Setup.
