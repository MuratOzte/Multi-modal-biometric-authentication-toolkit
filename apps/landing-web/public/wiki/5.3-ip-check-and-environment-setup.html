Purpose and Scope

This page details the environment setup, dependency management, virtual environments (.venv-face, .venv-voice, .venv-card), GPU/CUDA configuration, FFmpeg integration, and network/IP check infrastructure (including VPNAPI signals and ip_check.py) for SecureKit's Python biometric and intelligence workers. It explains how system preflight checks validate these dependencies before runtime execution.

1. Python Virtual Environments and Dependency Isolation

SecureKit segregates Python dependencies into dedicated virtual environments per biometric modality (.venv-face, .venv-voice, .venv-card). This isolation prevents library version conflicts and Windows DLL collision issues—such as those occurring when PyTorch is imported alongside PaddleOCR.

The preflight module validator defines explicit dependency requirements for each modality:

  • Face: numpy, PIL, torch, torchvision, facenet_pytorch scripts/biometric-preflight.py 8-9
  • Voice: numpy, torch, torchaudio, whisper, speechbrain, imageio_ffmpeg scripts/biometric-preflight.py 10
  • Card: numpy, PIL, cv2, yaml, rapidfuzz, skimage, torch, open_clip, paddle, paddleocr scripts/biometric-preflight.py 13

3. Hardware Requirements: GPU/CUDA and FFmpeg


GPU and CUDA Validation


For face and voice modalities, biometric-preflight.py inspects PyTorch CUDA availability (torch.cuda.is_available()) scripts/biometric-preflight.py 27-33


    

  • Configuration parameters like FACE_DEVICE, FACE_REQUIRE_GPU, or Face__RequireGpu dictate whether GPU acceleration is strictly required scripts/biometric-preflight.py 30-31
    • 

  • If REQUIRE_GPU is enabled, preflight checks fail if CUDA is absent.

FFmpeg Requirements


Voice verification relies heavily on audio preprocessing via FFmpeg. The preflight check verifies FFmpeg availability using shutil.which("ffmpeg"), with an automatic fallback to binaries bundled by imageio_ffmpeg scripts/biometric-preflight.py 34-44

4. IP Check and VPNAPI Signals


Network verification and IP intelligence modules (ip_check.py) evaluate client connection metadata to assess fraud risk during authentication sessions.


Key Signal Categories


    

  • VPN / Proxy Detection: Queries IP intelligence providers (such as VPNAPI) to flag commercial VPN exits, data centers, and anonymous proxy ranges.

  • Geolocation Risk: Validates client IP geographic origin against expected user profiles or session bounds.
