Purpose and Scope

This section details the backend verification, state management, and risk evaluation components implemented within the ASP.NET Core API (apps/securekit-api). Specifically, this covers dynamic and fixed keystroke biometric parsing, Exponential Moving Average (EMA) user profiles, session state persistence (SessionStore), challenge lifecycle management (ChallengeStore), multi-signal risk decision logic (SessionRiskEvaluator), and network/IP verification (IpCheckService).

State and Challenge Stores

Session and challenge data are maintained in-memory using thread-safe singleton services configured at bootstrap.

ChallengeStore

The ChallengeStore manages timed, single-use authentication and biometric challenges.

  • TTL: Challenges enforce a default Time-To-Live (typically 120 seconds).
  • Consumption: Challenges support strict single-use semantics; once consumed during verification or registration, subsequent validation attempts fail.
  • Registration: Registered as a singleton service in apps/securekit-api/Program.cs 10

SessionStore

The SessionStore tracks active user sessions.

  • TTL: Sessions enforce a default sliding or absolute timeout (e.g., 15 minutes as described in MIGRATION_TO_ASPNET10_PLAN.md 119).
  • State Merging: Signals and intermediate biometric verifications are accumulated across session lifecycle calls.
  • Registration: Registered as a singleton service in apps/securekit-api/Program.cs 13

Keystroke Verification and EMA Profiles

Keystroke dynamics validation spans both dynamic behavioral typing analysis and fixed-text template matching via Python worker bridges.

Dynamic Keystroke and Session Verification

  • SessionKeystrokeVerifier: Evaluates dynamic typing patterns submitted during session checks against established user baselines.
  • Metrics & EMA Profiles: Calculates timing metrics (dwell time, flight time) and updates user behavioral templates using Exponential Moving Average (EMA) profile updates MIGRATION_TO_ASPNET10_PLAN.md 125-126

Fixed Keystroke and Python Bridge

  • FixedKeystrokeStore: Manages storage and retrieval of fixed-text keystroke enrollment templates.
  • KeystrokePython: Interfaces with the underlying Python keystroke verification worker apps/securekit-api/Program.cs 17-18

Risk Evaluation and Network Verification

Risk evaluation aggregates multi-modal signals (keystrokes, face, voice, card, and network telemetry) to determine access outcomes.

SessionRiskEvaluator

The SessionRiskEvaluator processes accumulated verification signals against configured security policies:

  • Outcomes: Returns decision states including allow, step_up (or step-up), and deny MIGRATION_TO_ASPNET10_PLAN.md 121-124
  • Policy Checks: Evaluates risk scores, country restrictions, VPN/proxy flags, and step-up authentication order requirements.
  • Registration: Registered as a singleton in apps/securekit-api/Program.cs 14

Network Verification (IpCheckService)

The IIpCheckService / IpCheckService evaluates client IP addresses against known VPN, data center, and geolocation databases to feed risk telemetry into the evaluation pipeline.

  • Registration: Registered as a singleton in apps/securekit-api/Program.cs 16
