The apps/demo-web package is a Vite-powered React single-page and multi-page application that serves as the primary demonstration and playground frontend for the SecureKit toolkit. It showcases registration, authentication, multi-modal biometric enrollment and verification (keystroke, face, voice, and card), network signal checks, and risk scoring using @securekit/web-sdk. This page details its build configuration, backend target resolution, proxy rewriting rules, UI entry points (auth.html), and the end-to-end smoke testing harness (aspnet-smoke.ts).

Backend Resolution (api-target.ts)

To support seamless switching between the legacy Express backend and the modern ASP.NET Core backend during development and testing, apps/demo-web/api-target.ts exports resolveApiTarget() apps/demo-web/api-target.ts 1-8

The resolution function evaluates environment variables loaded by Vite:

  1. It checks for an explicit target override (VITE_SECUREKIT_DEV_PROXY_TARGET), taking highest precedence apps/demo-web/api-target.ts 2-3
  2. It falls back to VITE_SECUREKIT_API_BACKEND (defaulting to aspnet) apps/demo-web/api-target.ts 4
  3. If set to aspnet, it resolves to http://localhost:3002 apps/demo-web/api-target.ts 5; if set to node, it resolves to http://localhost:3001 apps/demo-web/api-target.ts 6 Otherwise, it throws an error apps/demo-web/api-target.ts 7

Application UI and Multi-Page Build (auth.html)

The demo application is structured as a multi-page Vite bundle defined in apps/demo-web/vite.config.ts under rollupOptions.input apps/demo-web/vite.config.ts 45-52:

  • index: Maps to apps/demo-web/index.html apps/demo-web/vite.config.ts 48 serving the main dashboard and biometric playground.
  • auth: Maps to apps/demo-web/auth.html apps/demo-web/vite.config.ts 49 serving dedicated authentication flows, consent modals, and challenge-response entry points.

The UI leverages @securekit/web-sdk to execute client-side collection (keystroke dynamics, face capture, voice recordings, and card capture) and communicates with the backend APIs via standard REST calls and typed transport error handling.

ASP.NET Smoke Test Script (aspnet-smoke.ts)

The integration testing and acceptance of the demo application against the ASP.NET Core API is automated via apps/demo-web/scripts/aspnet-smoke.ts apps/demo-web/scripts/aspnet-smoke.ts 1-95

This script performs the following validation stages:

  1. Unit Testing Target Resolution: Asserts proper behavior of resolveApiTarget with various environment configurations apps/demo-web/scripts/aspnet-smoke.ts 12-15
  2. Temporary Environment Provisioning: Creates a temporary directory apps/demo-web/scripts/aspnet-smoke.ts 17 and spawns the compiled ASP.NET Core API binary (SecureKit.Api.dll) on a dynamic port (http://127.0.0.1:0) apps/demo-web/scripts/aspnet-smoke.ts 21-33
  3. Vite Dev Server Spin-up: Programmatically launches a Vite dev server pointing to the running ASP.NET Core instance apps/demo-web/scripts/aspnet-smoke.ts 46-50
  4. End-to-End SDK Verification: Instantiates SecureKitClient and executes a comprehensive integration battery: health checks, user registration, consent granting, login, session creation, network/location verification, keystroke dynamic enrollment and challenge verification, face reference enrollment and verification (including sliding window), voice challenge-response verification, card enrollment/verification, and biometric cleanup apps/demo-web/scripts/aspnet-smoke.ts 52-95
