The testing and acceptance tooling in SecureKit provides a multi-tiered validation structure designed to ensure software correctness, protocol parity between legacy and modern backends, and rigorous physical/model-level biometric validation. The test pyramid spans programmatic unit and integration tests in .NET (apps/securekit-api.tests), protocol and stage parity scripts, environment validation, and isolated biometric execution harnesses (scripts/biometric-preflight.mjs, scripts/biometric-acceptance.mjs) package.json 14-21 docs/BIOMETRIC_ACCEPTANCE.md 1-139

The biometric preflight utility (scripts/biometric-preflight.mjs) evaluates local environment health before executing biometric workloads docs/BIOMETRIC_ACCEPTANCE.md 8-21 It verifies Python dependencies, CUDA availability for face and voice workers, and FFmpeg tooling for audio processing without invoking full weight downloads docs/BIOMETRIC_ACCEPTANCE.md 16-21 Binary resolution prioritizes environment variables like *_PYTHON_BIN, local virtual environments (.venv-*), and system paths docs/BIOMETRIC_ACCEPTANCE.md 23-26

6.2 Biometric Acceptance Harness

The biometric acceptance harness (scripts/biometric-acceptance.mjs) orchestrates end-to-end black-box testing against an isolated, temporary instance of the ASP.NET Core API docs/BIOMETRIC_ACCEPTANCE.md 56-64 It relies on manifest-driven configuration (prepare:biometric-acceptance, status:biometric-acceptance) to validate face, voice, and card pipelines while maintaining privacy-safe reporting and zero git pollution of local biometric samples docs/BIOMETRIC_ACCEPTANCE.md 65-140

6.3 .NET Test Suite

The .NET test suite (apps/securekit-api.tests) provides automated verification for controllers, verification service logic, dependency injection, and health endpoints. It ensures that the modern ASP.NET Core backend preserves the required API contracts and business logic expected by the SDK and verification bridges.

For details, see .NET Test Suite.
