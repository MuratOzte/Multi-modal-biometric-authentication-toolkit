Purpose and Scope

The Biometric Acceptance Harness provides an end-to-end local validation framework for SecureKit's multi-modal biometric authentication models (face, voice, card). While protocol and HTTP-level compliance are handled by automated test suites, actual hardware, model weights, and inference outputs are verified using the acceptance scripts located under scripts/ and documented in docs/BIOMETRIC_ACCEPTANCE.md docs/BIOMETRIC_ACCEPTANCE.md 1-7

The harness operates by spinning up an isolated, ephemeral instance of the C# ASP.NET Core API with temporary file stores, reading a user-supplied JSON manifest containing consented local sample assets, exercising the production Python workers (face_verification.py, voice_worker.py, main.py), and asserting strict pass/fail criteria without leaking privacy-sensitive paths, embeddings, or transcription texts into shared git history or logs docs/BIOMETRIC_ACCEPTANCE.md 56-64

Validation Rules and Constraints

  • File Types: Audio files must use extensions .wav, .webm, .mp3, .m4a, or .ogg. Images must use .jpg, .jpeg, .png, or .webp docs/BIOMETRIC_ACCEPTANCE.md 124
  • Size Limits: Audio samples are capped at 12 MiB, and image samples are capped at 5 MiB docs/BIOMETRIC_ACCEPTANCE.md 125
  • Distinctness: Reusing the exact same file path or identical file contents (verified via SHA-256 digests) across positive and negative captures triggers validation errors such as FACE_DISTINCT_SAMPLES_REQUIRED, VOICE_DISTINCT_SAMPLES_REQUIRED, or CARD_DISTINCT_SAMPLES_REQUIRED scripts/biometric-acceptance.mjs 34-38 scripts/biometric-acceptance.test.mjs 98-110
  • Voice Requirements: Voice manifests require exactly three enrollment samples, a sameSpeaker sample, a differentSpeaker sample, and a distinct wrongText string scripts/biometric-acceptance.mjs 46-51

Isolated Ephemeral API Execution and Worker Binding

To prevent pollution of existing profile stores and test against clean state, the test runner spawns an isolated instance of the ASP.NET Core API (SecureKit.Api.dll) on a randomized ephemeral port (http://127.0.0.1:0) docs/BIOMETRIC_ACCEPTANCE.md 58-63 scripts/biometric-acceptance.mjs 84-110
