Overview and Scope

The Biometric Preflight subsystem (scripts/biometric-preflight.mjs and scripts/biometric-preflight.py) provides automated validation of runtime environments, third-party python dependencies, hardware acceleration (CUDA), and external system binaries (such as ffmpeg) required by SecureKit's multimodal biometric verification workers. Before spinning up Python subprocess bridges in the ASP.NET Core API or legacy Node backend, the preflight script executes a series of safe, non-invasive probes that verify module importability without loading heavy ML weights into memory or downloading model checkpoints.

Binary Resolution Order

The Node.js orchestrator (scripts/biometric-preflight.mjs) resolves the appropriate Python interpreter for each biometric domain (face, voice, and card) using a strict precedence order.

The binary resolution order evaluates:

  1. Explicit Environment Variables: Checks ${PREFIX}_PYTHON_BIN, PYTHON_BIN, and configuration-mapped command properties scripts/biometric-preflight.mjs 41
  2. Local Virtual Environments: Checks if a local workspace virtual environment exists at .venv-face, .venv-voice, or .venv-card scripts/biometric-preflight.mjs 42
  3. System Fallbacks: Defaults to platform-specific system Python (py on Windows, python3 on POSIX systems) scripts/biometric-preflight.mjs 45

Python Probe Implementation and Checks

The worker-side script (scripts/biometric-preflight.py) executes imports wrapped in contextlib.redirect_stdout and contextlib.redirect_stderr to prevent third-party initialization noise from corrupting JSON payloads scripts/biometric-preflight.py 21-25

The script validates distinct dependency arrays per domain:

  • Face: numpy, PIL, torch, torchvision, facenet_pytorch scripts/biometric-preflight.py 9
  • Voice: numpy, torch, torchaudio, whisper, speechbrain, imageio_ffmpeg scripts/biometric-preflight.py 10
  • Card: numpy, PIL, cv2, yaml, rapidfuzz, skimage, torch, open_clip, paddle, paddleocr scripts/biometric-preflight.py 13

Run-Log Output and Acceptance State

Upon completing probes for all modules, scripts/biometric-preflight.mjs writes a consolidated diagnostic report to .run-logs/biometric-preflight.json scripts/biometric-preflight.gjs 8-58

The JSON report schema contains:

  • checkedAt: ISO timestamp of the run scripts/biometric-preflight.mjs 9
  • dependenciesPassed: Boolean flag indicating whether all required (non-optional) checks passed across all modules scripts/biometric-preflight.mjs 9-56
  • modelAcceptance: Status string ("pending", "passed", or "failed") scripts/biometric-preflight.mjs 10
  • hardwareAcceptance: Status string for GPU/camera/microphone availability scripts/biometric-preflight.mjs 10-59
  • modules: Array of individual module check results, runtime sources, and specific error metadata scripts/biometric-preflight.mjs 10-50

If any non-optional check fails, the preflight script terminates with exit code 1, halting automated pipelines before invalid worker environments can be initialized scripts/biometric-preflight.mjs 60
