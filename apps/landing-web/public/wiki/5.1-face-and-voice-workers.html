Face and Voice Workers

This page details the implementation of the face and voice biometric workers within the SecureKit toolkit. These Python-based workers handle the core logic for face enrollment/verification using MTCNN and FaceNet, and voice enrollment/verification using Whisper and SpeechBrain. They are invoked by the ASP.NET Core API via a controlled process bridge.

Face Verification Worker

The face verification worker, located at python/face_verification/face_verification.py python/face_verification/face_verification.py 1-177 is responsible for detecting faces, extracting face embeddings, and comparing them for verification. It utilizes the MTCNN (Multi-task Cascaded Convolutional Networks) for face detection and FaceNet for generating high-dimensional face embeddings.

Implementation Details

The face_verification.py script can operate in two main modes:

  1. Enrollment: Takes an image, detects a face, and returns its embedding.
  2. Verification: Takes a reference embedding and a probe image, detects a face in the probe, extracts its embedding, and calculates the similarity between the two embeddings.

The script uses argparse python/face_verification/face_verification.py 130-147 to handle command-line arguments for specifying the operation mode (--enroll or --verify), input files (--image, --reference, --probe), and output format (--json).

Key components and their roles:

  • FaceDetector class: python/face_verification/face_verification.py 16-40
    • Initializes the MTCNN model for face detection.
    • The detect_face method python/face_verification/face_verification.py 29-40 takes an image (as a NumPy array) and returns the bounding box coordinates of the detected face.
  • FaceEmbedder class: python/face_verification/face_verification.py 43-67
    • Initializes the FaceNet model for embedding generation.
    • The get_embedding method python/face_verification/face_verification.py 56-67 takes a cropped face image and returns its 512-dimensional embedding.
  • FaceVerifier class: python/face_verification/face_verification.py 70-100
    • Orchestrates the face detection and embedding process.
    • The enroll method python/face_verification/face_verification.py 79-84 detects a face in an image and returns its embedding.
    • The verify method python/face_verification/face_verification.py 86-100 takes a reference embedding and a probe image, extracts the probe's embedding, and calculates the cosine similarity between them. It also applies a configurable threshold (FACE_VERIFICATION_THRESHOLD) to determine if the faces match.

The script also includes basic liveness detection by checking for a single, well-defined face in the image. If multiple faces are detected or no face is found, it returns an error.

Voice Verification Worker

The voice verification worker, located at python/voice_verification/voice_verification.py python/voice_verification/voice_verification.py 1-200 handles voice enrollment and verification. It uses Whisper for speech-to-text transcription to ensure the spoken phrase matches a challenge text, and SpeechBrain for speaker verification to compare voice characteristics.

Implementation Details

The voice_verification.py script supports two primary operations:

  1. Enrollment: Takes an audio file and a challenge text, transcribes the audio using Whisper, verifies it against the challenge, and then extracts a speaker embedding using SpeechBrain.
  2. Verification: Takes an audio file, a challenge text, and a reference speaker embedding. It transcribes the audio, verifies it against the challenge, extracts a speaker embedding from the audio, and compares it to the reference embedding.

The script uses argparse python/voice_verification/voice_verification.py 160-177 for command-line argument parsing, allowing specification of operation mode (--enroll or --verify), input audio (--audio), challenge text (--challenge), and reference embedding (--reference).

Key components and their roles:

  • SpeechToText class: python/voice_verification/voice_verification.py 16-40
    • Initializes the Whisper model for speech transcription.
    • The transcribe method python/voice_verification/voice_verification.py 29-40 takes an audio file path and returns the transcribed text.
  • SpeakerEmbedder class: python/voice_verification/voice_verification.py 43-67
    • Initializes the SpeechBrain speaker verification model.
    • The get_embedding method python/voice_verification/voice_verification.py 56-67 takes an audio file path and returns a speaker embedding.
  • VoiceVerifier class: python/voice_verification/voice_verification.py 70-109
    • Orchestrates the transcription and speaker embedding processes.
    • The enroll method python/voice_verification/voice_verification.py 82-92 transcribes audio, checks against the challenge, and extracts a speaker embedding.
    • The verify method python/voice_verification/voice_verification.py 94-109 performs transcription, challenge verification, extracts a probe embedding, and calculates cosine similarity with a reference embedding. It uses VOICE_VERIFICATION_THRESHOLD for similarity comparison.

The script ensures that the transcribed text matches the provided challenge text, adding a layer of liveness and intent verification.
