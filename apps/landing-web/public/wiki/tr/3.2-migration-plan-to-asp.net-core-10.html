Amaç ve kapsam

Bu belge, packages/node-auth içindeki eski Node.js Express API’sini, istemci uygulamalarını değiştirmeden tam sözleşme uyumuyla apps/securekit-api içindeki yeni ve yüksek performanslı ASP.NET Core 10 API’sine (net10.0) taşımanın mimari planını tanımlar. MIGRATION_TO_ASPNET10_PLAN.md 1-6

İlk geçiş sırasında şu bileşenler korunur:

  • React/Vite demo uygulaması (apps/demo-web). MIGRATION_TO_ASPNET10_PLAN.md 8-10
  • TypeScript web SDK’sı (packages/web-sdk). MIGRATION_TO_ASPNET10_PLAN.md 8-11
  • Yüz, ses, kart, IP ve sabit metin yazım ritmi doğrulaması için Python işçileri. MIGRATION_TO_ASPNET10_PLAN.md 8-12
  • Mevcut HTTP rotaları, istek/yanıt veri şemaları ve hata yapıları. MIGRATION_TO_ASPNET10_PLAN.md 8-13

Python işçileri, C# hizmetlerinin doğrudan yönettiği kontrollü süreç köprüsüyle entegre edilir. MIGRATION_TO_ASPNET10_PLAN.md 15 Veritabanı geçişleri, parola güvenliği iyileştirmeleri ve gelişmiş kimlik doğrulama stratejisi değişiklikleri bu API uyumluluk geçişinden ayrı çalışmalar olarak ele alınır. Geçiş ilkeleri ve yöntem

Geçiş, gerileme olmaması kuralına bağlıdır; ilgili C# modülleri tüm doğrulama kontrollerinden geçene kadar eski Node API çalışır durumda tutulur. MIGRATION_TO_ASPNET10_PLAN.md 34-42

  1. Geri dönüşün korunması: Tüm C# modülleri bütün test düzeneklerini geçene kadar Node API (packages/node-auth) korunur. MIGRATION_TO_ASPNET10_PLAN.md 34-36
  2. Aşamalı commit’ler: Her geçiş adımı küçük, bağımsız ve geri alınabilir commit’lerden oluşur. MIGRATION_TO_ASPNET10_PLAN.md 37
  3. Önce sözleşme: Şemalar ve testler uygulamadan önce oluşturulur. MIGRATION_TO_ASPNET10_PLAN.md 38
  4. Kesin eşdeğerlik: Rotalar, HTTP yöntemleri, durum kodları ve JSON alan tanımları değiştirilmez. MIGRATION_TO_ASPNET10_PLAN.md 39
  5. İki ortamda doğrulama: Aynı uç noktalar, yanıt eşdeğerliğini doğrulamak için hem Node hem C# ortamında çalıştırılır. MIGRATION_TO_ASPNET10_PLAN.md 40
  6. Kontrolle ilerleme: Mevcut aşamanın testleri geçmeden sonraki aşamaya geçilemez. MIGRATION_TO_ASPNET10_PLAN.md 41

Kaynaklar: MIGRATION_TO_ASPNET10_PLAN.md 34-42
