.NET Test Suite (apps/securekit-api.tests), SecureKit ASP.NET Core API’sinin (apps/securekit-api) entegrasyon ve birim test çerçevesidir. Denetleyici uç noktalarını, hizmet katmanlarını, biyometrik Python süreç köprülerini, hata dönüştürme sözleşmelerini ve sağlık izleyicilerini beklenen davranışa ve eski Node.js API eşdeğerliğine göre doğrular.

Test mimarisi ve destek altyapısı

Test takımı, WebApplicationFactory<TEntryPoint> kullanarak bellekte API örnekleri başlatmak için ağırlıklı olarak Microsoft.AspNetCore.Mvc.Testing aracına dayanır. ContractAssert gibi özel test düzenekleri ve yardımcılar JSON yanıt yapılarını, HTTP durumlarını ve hata biçimlerini doğrular.

Kart doğrulama entegrasyonu (StageSevenTests) gibi aşamaya özgü testler; dosya işlemlerini ayıran, Python yürütme yollarını taklit eden ve SECUREKIT_PROFILE_STORE, Card:ReferenceDirectory, Card:ScriptPath gibi anahtarları değiştiren özel web uygulaması fabrikaları oluşturur.

Yedinci aşama ve kart doğrulama testleri

StageSevenTests; kart kaydı, referans listeleme, eşik doğrulama ve Python köprü hata eşlemelerini kapsamlı test eder. Test fabrikası geçici depolama kökleri kurar ve farklı başarı/hata koşullarını taklit etmek için Python test betiklerini (card-stage7.py) eşler.

StageSevenTests içindeki temel test davranışları:

  • Referans listeleme ve okunabilirlik: Yalnızca geçerli görüntü biçimlerinin listelendiğini ve etiketlerin düzgün biçimlendirildiğini doğrular [apps/securekit-api.tests/StageSevenTests.cs:58-65].
  • Protokol ve karar akışı: Eşleşmeleri, en iyi eşleşme kararlarını ve otomatik geçici dosya temizliğini test eder [apps/securekit-api.tests/StageSevenTests.cs:66-74].
  • Kayıt normalleştirme: Kullanıcı kimliği temizleme, referans dosyası değiştirme ve saklanmış referans kullanımını test eder [apps/securekit-api.tests/StageSevenTests.cs:75-85].
  • İşçi hata eşleme: Geçersiz çıktıları, şema hatalarını, zaman aşımını ve süreç hatalarını standart HTTP durumlarına (502, 504, 404) ve hata kodlarına (PYTHON_OUTPUT_INVALID, PYTHON_TIMEOUT, REFERENCE_NOT_FOUND) dönüştürür [apps/securekit-api.tests/StageSevenTests.cs:86-100].
  • Girdi doğrulama: Aralık dışı eşikleri (NaN, Infinity, -1, 2) ve hatalı dosya yüklemelerini reddeder [apps/securekit-api.tests/StageSevenTests.cs:101-112].

Kaynaklar: apps/securekit-api.tests/StageSevenTests.cs 86-100

Sağlık ve temel sözleşme testleri

HealthTests; temel hizmet erişimini, eski Node API sözleşme eşdeğerliğini ve iç test uç noktalarının üretimde gizlenmesi gibi sınır korumalarını doğrular.

Test sınıfı, şu kontroller için ApiFactory enjekte eder:

  • Sağlık uç noktası sözleşmesi: GET /health çağrısının eski sözleşmeyle aynı {"ok":true} gövdesini HTTP 200 OK ile döndürdüğünü doğrular [apps/securekit-api.tests/HealthTests.cs:8-15].
  • Rota doğrulama: referenceImage gibi zorunlu çok parçalı alanlar eksik olduğunda yapılandırılmış hata ayrıntılarıyla 400 Bad Request üretildiğini doğrular [apps/securekit-api.tests/HealthTests.cs:17-24].
  • Güvenlik izolasyonu: /__test/throw gibi iç altyapı denetim rotalarının dışa açılmadığını ve 404 Not Found döndürdüğünü doğrular [apps/securekit-api.tests/HealthTests.cs:27-32].
