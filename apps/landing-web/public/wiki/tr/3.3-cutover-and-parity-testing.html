Bu sayfa, eski Node/Express API’sinden (packages/node-auth) SecureKit ASP.NET Core 10 API’sine (apps/securekit-api) geçişte kullanılan stratejiyi, sunucu seçimi ortam değişkenlerini, eşdeğerlik test düzeneklerini ve doğrulama test verilerini belgeler. aspnet-parity.mjs çalıştırıcısını, birinci ile yedinci aşama arasındaki eşdeğerlik betiklerini ve .run-logs/ altındaki çalışma günlüklerinin oluşturulmasını kapsar.

Sunucu seçimi ve ortam yapılandırması

Monorepo, Vite geliştirme proxy’sinin arkasında eski Node/Express API’sini veya yeni ASP.NET Core API’sini çalıştırmayı destekler. docs/ASPNET_CUTOVER.md 1-31 Sunucu seçimi, kök çalıştırma betikleri ve Vite yapılandırmasında başlangıçta değerlendirilen ortam değişkenleriyle yönetilir. docs/ASPNET_CUTOVER.md 13-23

Yapılandırma değişkenleri

  • VITE_SECUREKIT_API_BACKEND: Hedef seçimini yönetir. aspnet değeri istekleri 3002 portuna, node değeri 3001 portuna yönlendirir. docs/ASPNET_CUTOVER.md 21-22
  • VITE_SECUREKIT_DEV_PROXY_TARGET: VITE_SECUREKIT_API_BACKEND değerinden önce gelen açık URL geçersiz kılma seçeneğidir. docs/ASPNET_CUTOVER.md 20-21
  • Varsayılan portlar: C# ASP.NET Core API 3002, Node/Express API 3001, Vite geliştirme sunucusu 5173 portunu kullanır. docs/ASPNET_CUTOVER.md 8-10

Birinci ile yedinci aşama arasındaki eşdeğerlik betikleri

Eşdeğerlik testleri, farklı yönlendirme alanlarını ve doğrulama sınırlarını kapsayan yedi işlevsel aşamaya ayrılır:

  • Aşama 1–3: Temel kimlik doğrulama sözleşmeleri, oturum yönetimi, risk değerlendirme şemaları ve doğrulama isteği depoları.
  • Aşama 4–6: Biyometrik yönlendirme modülleri (yüz vektörleri, ses doğrulama, kayan pencereler, yazım ritmi profilleme).
  • Aşama 7: Kart doğrulama uç noktaları, çok parçalı form işleme, referans yönetimi, hata enjeksiyonu ve Python süreç köprüsü davranışı. packages/node-auth/scripts/stage-seven-parity.ts 1-114

Normalleştirme ve doğrulama mantığı

Depolama yolları, sistemin ürettiği geçici dizinler ve değişken zamanlar (enrolledAt, updatedAt) Node ve .NET ortamları arasında farklılaştığı için eşdeğerlik betikleri ayrıntılı karşılaştırmadan önce yanıtları normalleştirir. packages/node-auth/scripts/stage-seven-parity.ts 46-57

// Normalization logic mapping volatile paths and dates
const normalize = (value: any, key = ""): any => {
  if (Array.isArray(value)) return value.map(v => normalize(v));
  if (value && typeof value === "object") return Object.fromEntries(Object.entries(value).map(([k, v]) => [k, normalize(v, k)]));
  if (["updatedAt", "enrolledAt", "cardReferenceEnrolledAt"].includes(key)) return "<time>";
  if (typeof value === "string") {
    for (const [name, replacement] of variablePaths) value = value.split(name).join(replacement);
    value = value.replace(/[^\s"']*securekit-card-[^/\\\s"']+[\\/]/g, "<temp>/").replaceAll("\\", "/");
  }
  return value;
};

Test verileri ve deterministik test (card-stage7.py)

Yerel PyTorch, CUDA veya PaddleOCR ortamı gerektirmeden güvenilir testler çalıştırmak için yedinci aşama deterministik bir Python protokol düzeneği (packages/node-auth/scripts/fixtures/card-stage7.py) kullanır. packages/node-auth/scripts/fixtures/card-stage7.py 1-53

Protokol düzeneğinin davranışı

Betik, JSONL protokol çerçeveleriyle stdin/stdout üzerinden iletişim kurar. Gerçek makine öğrenmesi modellerini çağırmadan farklı başarı ve hata durumlarını taklit etmek için örnek görüntü yollarını inceler:

  • timeout: İşçi zaman aşımı yönetimini test etmek için kasıtlı 30 saniyelik gecikme oluşturur. packages/node-auth/scripts/fixtures/card-stage7.py 14-15
  • invalid: Ayrıştırıcı hata toparlanmasını test etmek için JSON dışı çıktı üretir. packages/node-auth/scripts/fixtures/card-stage7.py 16-18
  • stdout / stderr: Çıktı boşaltma sınırlarını doğrulamak için büyük veri tamponları veya hata akışları üretir. packages/node-auth/scripts/fixtures/card-stage7.py 19-24
  • dependency: Eksik Python modülü istisnalarını (örneğin No module named 'paddleocr') taklit eder. packages/node-auth/scripts/fixtures/card-stage7.py 41-42
